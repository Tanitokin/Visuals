# Audio files (add later — the menu works silently without them)

Drop these files here, with these exact names:

| File | Sound | Volume |
|------|-------|--------|
| `crt-hum.mp3` | ruido grave constante, casi imperceptible (loop) | 0.08 |
| `menu-beep.mp3` | beep seco tipo consola vieja (cursor se mueve) | 0.18 |
| `glitch.wav` | distorsión digital corta (transiciones glitch) | 0.25 |
| `warning-tone.mp3` | tono bajo de alarma (danger > 90%) | 0.20 |
| `file-lock.wav` | golpe mecánico / confirmación (archivo bloqueado) | 0.35 |

Volumes and paths are configured in the `AUDIO` object at the top of the
`<script>` in `index.html`.
