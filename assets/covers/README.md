# Cover images

Drop one image per city here. The scene picks files by their **number prefix**,
so any extension (`.png`, `.jpg`, `.jpeg`, `.webp`) and any name after the
number works. Recommended portrait-ish or square art (it is fit-to-frame,
letterboxed cleanly on a dark backing).

Expected prefixes (suggested filenames):

| # | City          | Suggested filename            |
|---|---------------|-------------------------------|
| 01| Gotham City   | `01_gotham_city.png`          |
| 02| Midgar        | `02_midgar.png`               |
| 03| Los Angeles   | `03_los_angeles.png`          |
| 04| Rapture       | `04_rapture.png`              |
| 05| City 17       | `05_city_17.png`              |
| 06| Mega-City One | `06_mega_city_one.png`        |
| 07| Zaun          | `07_zaun.png`                 |
| 08| Yharnam       | `08_yharnam.png`              |
| 09| The City      | `09_the_city.png`             |
| 10| Silent Hill   | `10_silent_hill.png`          |
| 11| New Crobuzon  | `11_new_crobuzon.png`         |
| 12| Commorragh    | `12_commorragh.png`           |
| 13| Dis           | `13_dis.png`                  |

Any city without a matching file renders a clean "COVER PENDING" placeholder.
